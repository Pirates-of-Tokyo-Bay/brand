# Cast handbook / 新メンバーオリエンテーション

What a new Pirate needs to know in their first month. We publish it because other
improv groups keep asking how we run a two-language show, and because it is easier
to point at a link than to explain it again.

| File | Language |
|---|---|
| [`onboarding-bilingual.md`](onboarding-bilingual.md) | Japanese and English side by side. This is the one we give new members. |
| [`onboarding-en.md`](onboarding-en.md) | English only |
| [`onboarding-ja.md`](onboarding-ja.md) | 日本語のみ |

## What is inside

- Mission, vision and values, and what they look like as actual behavior
- How the monthly show runs, from load-in to strike
- The multilingual performance framework: reading the room, balancing languages,
  and the on-stage techniques that keep a mixed audience with you
- Marketing and social rules for cast-made content

## Useful even if you are not a Pirate

The **multilingual performance framework** section is the part with the most
general value. Getting a room where half the audience does not speak the
performer's language to laugh at the same moment is a specific craft problem, and
most of what is written about improv assumes everyone shares one language.

If you run a show in a mixed-language city, take what is useful.
