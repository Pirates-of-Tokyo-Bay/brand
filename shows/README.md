# Show format library / 公演フォーマット一覧

Every short-form game Pirates of Tokyo Bay has used on stage, with the
language it works in, how many performers it needs, and how often we have
actually played it.

This is real production data, not a wish list. The frequency column is a
count of appearances across our recorded shows, so it doubles as a ranking
of what reliably works in front of a mixed-language audience.

Raw data: [`game-catalogue.csv`](game-catalogue.csv) and [`show-history.csv`](show-history.csv).

## Column meanings

- **Language**: `Both` means the game holds up with Japanese and English
  running at the same time on stage. `EN or JA` means it works in either
  language but pick one per round.
- **Players**: the number of performers the format needs.
- **Times played**: appearances across our recorded show history.

## A note on the show history data

`show-history.csv` records what we played, in what order, in what language, from
2015 to 2025. The columns listing which performers were in each game have been
removed. Set lists are useful to other groups. A ten year record of who was on
stage on which night is personal data about real people, and it is not ours to
publish.

Our roster file is not in this repository at all, for the same reason. See
[`../tools/README.md`](../tools/README.md).
